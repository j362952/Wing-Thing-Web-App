# WingThing 🐤

Ein Flappy-Bird-Klon für den Browser – komplett in **einer einzigen HTML-Datei**, ohne Frameworks, ohne Installation.

**▶ Direkt spielen:** _Link nach Aktivierung von GitHub Pages hier eintragen_

<!-- Screenshot einfügen: ![Screenshot](screenshot.png) -->

## Steuerung

| Taste | Aktion |
|---|---|
| Leertaste | Flügelschlag |
| P / Esc | Pause |

## Features

- Schwerkraft-Physik und zufällige Hindernisse
- Score-Zähler und Highscore (gespeichert im Browser via `localStorage`)
- Pause-Funktion, Startmenü, Highscore-Ansicht und Game-Over-Screen

## Technik

- HTML5 Canvas
- Vanilla JavaScript und CSS, alles in `index.html`
- Keine Abhängigkeiten, kein Build-Schritt

## Lokal starten

`index.html` herunterladen und im Browser öffnen – fertig.
